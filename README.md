# Date Calculator

Scaffolded Next.js + React + TypeScript application with PrimeReact theme infrastructure.

## Tech Stack

- Next.js
- React
- TypeScript
- PrimeReact
- PrimeFlex
- PrimeIcons
- Chart.js
- react-chartjs-2
- date-fns
- react-hook-form
- zustand

## Theme System

- Default theme is `dark-synth`.
- Theme is stored in `localStorage` using key `cpt-theme`.
- Current built-in themes:
  - `dark-synth`
  - `dark`
  - `light`
  - `ms-access-2010`

## Development

Run the local dev server:

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
